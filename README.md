# 여울관: 남겨 둔 자리

`YEOWUL-full-draft-r03.zip`과 프로젝트의 미스터리 게임 설계 가이드를 바탕으로 만든 정적 웹 추리 게임 구현본입니다.

## 실행

별도 빌드는 필요하지 않습니다. 저장소를 내려받은 뒤 최신 Chromium 계열 브라우저에서 `index.html`을 열거나, 저장소 루트에서 간단한 정적 서버를 띄울 수 있습니다.

```bash
python -m http.server 8080
```

그 후 `http://localhost:8080`에 접속합니다.

## 플레이 구조

- 프롤로그 + CH01–CH06 + 에필로그의 r03 대본 진행
- r03가 SHA-256으로 고정 참조한 채택 도입부 `C_PR_01..05` 포함
- 52개 자료의 최초 획득과 즉시 상세 확인
- 실제로 만난 인물만 등록되는 인물 기록
- 현재까지 알게 된 장소와 연결만 표시하는 개략 지도
- 실제로 진행한 발화와 선택 결과만 남는 대화 기록
- D01–D30, Q01–Q06의 36개 추리/추궁 과제
- 작성된 오류 반응 71개와 복수 정답 경로 보존
- 틀린 확정 추리 시 `여유 -2`; 0이 되면 자료·기록·답안을 유지한 채 4로 회복
- D/Q 및 필수 병목용 H0–H4 요청형 힌트
- 추리 도중 자료·인물·지도·대화·노트를 열어도 답안 선택 유지
- 일부 추리는 본선 장면 전에도 조건이 갖춰지면 `열린 추리`에서 시도 가능
- `localStorage` 자동 저장/수동 저장 및 이어하기
- 이름 입력을 반영하되 주인공의 안정적인 캐릭터 ID는 유지
- 관계/방식 선택을 저장하고 이후 조건부 대사에 반영
- 장면별 상황 SVG, 인물 초상 SVG, 자료별 문서/도식형 상세 뷰
- 데스크톱/모바일 반응형 레이아웃, 텍스트 확대

## 런타임 데이터

대본 데이터는 gzip + base64로 압축한 뒤, 전송 무결성을 검증한 작은 script 조각으로 나뉩니다. 실행 시 `src/data/part01~12`, `src/data-tail/tail01~09`, `src/data-tail-safe/tail10~23`의 a/b 조각을 순서대로 합쳐 복원합니다. 게임 런타임도 `src/runtime-safe/part01~06`을 합쳐 복원하며, `src/loader.js`가 r03 revision·자료 수·조각 수를 확인한 뒤 실행합니다. 유지보수용 비압축 런타임은 로컬 작업본의 `src/game.js`가 기준입니다.

원본 출처와 도입부 dependency 검증은 [`docs/source-audit.md`](docs/source-audit.md)에 기록했습니다.

## 검증

```bash
node --check src/game.js
node tools/verify.mjs
node tools/simulate.mjs
```

현재 기계 검증 결과는 다음 범위를 확인합니다.

- 메인 장면 106개, 선택 장면 18개
- E01–E52 자료 52개
- 인물 10명
- D01–D30 + Q01–Q06 = 36개 추리 과제
- H0–H4 힌트 묶음 42개
- 이름 붙은 오답 경로 71개
- Q01의 두 증명 경로와 D30의 두 제시 순서
- 주요 지속 선택 `B_PR_01`, `B_PR_02`, `B_PLAYBACK_RESPONSE`, `B_EXHIBIT`, `B_SOUND`
- 기본 완주 시뮬레이션에서 52개 자료와 36개 추리를 모두 거쳐 엔딩 도달

자세한 상태와 한계는 [`docs/verification.md`](docs/verification.md)를 참고하세요. 자동 검증은 실제 재미, 체감 난이도, 시각적 완성도, 독립 플레이테스트를 대신하지 않습니다.
